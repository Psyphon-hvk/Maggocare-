MAGGOCARE WEBSITE
=================
Open index.html in any browser. No build step or server needed.

Pages:  index.html, how-it-works.html, conditions.html, our-lab.html, safety-faq.html, order.html
Assets: css/style.css, js/main.js, images/

WhatsApp number: edit ONE line at the top of js/main.js:
    const WHATSAPP_NUMBER = "254793935665";
(international format, digits only). Every WhatsApp button and the order form use it.
The footer/contact text showing "+254 793 935665" is plain text in each .html file.

Fonts: Poppins loads from Google Fonts (needs internet); falls back to system fonts offline.
Hosting: upload the whole folder to any static host (Netlify, GitHub Pages, cPanel, etc).
